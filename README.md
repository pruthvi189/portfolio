# Pruthvi Shah — Portfolio

Personal portfolio website showcasing ML engineering projects and skills.

## Tech Stack

- **Framework:** Next.js 16 + React 19
- **Styling:** Tailwind CSS 4
- **Animations:** Framer Motion
- **Language:** TypeScript

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
